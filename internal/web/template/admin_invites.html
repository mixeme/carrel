Add a user

Three ways, for three situations. Use whichever fits.

Invitation

The new user chooses their own password. You never see it.

By link

Creates a one-time link for you to copy and share. The new user chooses their own login when they open it.

By email

{{if $d.SMTPConfigured}}

Sends an invitation email with a one-time link. You will not see the link — only the recipient gets it.

{{else}}

Configure SMTP in Settings before sending invitations by email.

{{end}}

Temporary password

Until the user changes this password, you can sign in as them. Only use this when handing credentials over in person.

Self-registration

Visitors create their own account at a public form and confirm the email address before they can sign in. Off by default. Mail must be configured first.

{{if not $d.SMTPConfigured}}

Configure SMTP in Settings first. A confirmation email cannot be sent without it, so this cannot be turned on until mail works.

{{end}}
