# Ревью

**Opus** — проектирование типов и ревью написанного. Аудиты безопасности
(Fable) — в [security.md](../security.md); уроки, которые ловят повторы, — в
[development.md](../development.md). Ревью Typecase живут в его репозитории.

**Находки чинит сам рецензент** (решение владельца 07.09.2026), в коммите
ревью, по C-16: сначала проверка, красная на текущем коде, потом правка.
Отдельным планом уходит только то, что рецензент починить не может: слой ещё
не написан или решение продуктовое. Полные разборы свёрнуты; текст — в
истории git этого файла и `review-server.md`.
