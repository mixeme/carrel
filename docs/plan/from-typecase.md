# Записки из Typecase

Что из правок макета касается сервера. Макет правится в Typecase и копируется
сюда целиком (`docs/visual/carrel-ui-mockups.html`); здесь — то, что после
этого нужно сделать или знать серверной стороне. Обратный список — задачи
кадров, найденные сервером, — [to-typecase.md](to-typecase.md).

Прочитанное и сделанное удаляется; решения, которых нет в спеке, переносятся в
[architecture.md](../architecture.md). Разобранные записки — в истории git.

19. **Что сделать серверу.**
   - **Администрирование** (задача 30). У ожидающего приглашения логина нет —
     первая колонка теперь Address: адрес письма или «—» у ссылки
     (`s-admin-1`). `/invite/{token}` — свой кадр `s-auth-12`: Login,
     Password, Repeat password; у приглашения письмом адрес показан
     выключенным полем, у ссылки поля нет; приглашение, названное логином
     раньше, — логин выключенным полем. `s-auth-2` — только `/register`.
     После Create user — пароль один раз, как после сброса (`s-admin-17`).
     Без почты — Send invitation и Save регистрации выключены с причинами,
     карточка закрытой регистрации без «open» и без адреса (`s-admin-18`).
     Отказы у полей — с заглавной и точкой: «Login is already taken.»,
     «Password must be at least 8 characters.», «Enter one address, like
     name@example.org.» (`s-admin-19`). Policy — со своей кнопкой Save
     (`s-admin-6`).
   - **Сброс пароля и прочее** (задачи 31, 34). Сообщение `s-admin-2` и
     слова листа — по серверу; ответ на сброс — пароль один раз
     (`s-admin-14`); в Whose свой и отключённый — выключенными пунктами с
     причиной (`s-admin-15`, библиотека: `MenuItem.Reason`); короткий пароль
     — у поля (`s-admin-16`); логин для подтверждения — строка после
     Temporary password и её отказ (решение; `s-admin-13`, `s-admin-20`).
     Причина у «Make user» — с точкой. Внешний запуск выключен — карточки
     строки нет (решение): `TriggerBlock` не шлётся. Значок «local» —
     признак экземпляра (адрес в строке отвечает только изнутри сети): серверу
     слать его признаком страницы задания. Import и Export у задач — как у
     всех родов (`s-tasks-1`). Вступление 7.16 — публикация коллекции только в
     подключениях.
   - **Заметка, Related to, учётная запись** (задача 32). Соседи — по одной с
     каждой стороны (`s-notes-2`, `-3`, `-20`). День в списке Related to —
     «12 Aug»: у списков своя короткая форма, как в колонках строк; полная —
     в записи. Связь одна — первая `RELATED-TO`; незагруженная — пилюля с
     UID, карточка — имя и «contact», «By UID…» открывает строку для UID
     (`s-tasks-11`); у события поля нет — так. Строка чужих свойств — одной
     фразой, без моноширинного куска. Подпись тегов — «Tags» везде: панели и
     полные карточки (решение; формы правки — уже, v0.2.71). Key escrow при
     выключенной схеме — страница без подзаголовка и кнопок, одна строка
     (`account-14`).
   - **Перенос, From Files и прочее** (задача 33). В From Files хранилище
     только для чтения не приглушено и без значка — признак не нужен. Прочие
     отказы New folder — тем же сообщением под строкой имени, слова сервера.
     В листе загрузки отказ New folder — под строкой имени, пояснение листа
     остаётся (`s-files-19`). Подпись поля с приглушённой частью
     («Certificate fingerprint» + «SHA-256 · optional») — данные: слать
     приглушённую часть отдельно от подписи. Публичная страница одной записи:
     под заголовком — когда и где, «Monday, 10 August 2026, 10:00 – 11:00 ·
     Переговорная 2»; Lede не нужен — «read-only» говорит значок. В
     `s-contacts-20` — «2 events and tasks»: считаются только прочитанные.

## Для сведения — сервер не трогает

- **Подсказки «кандидат в дубликаты» в списках нет** (решение 24.09.2026):
  путь к паре — экран дубликатов; сворачивает строки только связывание.
- **Быстрая заметка** в кадрах — общий `NewSheet`, `/app/{kind}/quick`.
- **Столбец источника** — забота клиента (U-2.2).
- **Раскладка — забота клиента** (25.09.2026): панель подробностей 400 px на
  всех экранах, колонка заметки на весь экран — тоже 400 (в узкой рабочей
  области 296); поле во всю ширину занимает строку целиком; меню «⋯» полосы
  открыто только вместе с кнопкой и содержит то, что с полосы ушло.
- **«Упоминания»** — функция-кандидат; пока кадры не нарисованы и не
  утверждены, серверу строить нечего. В неё идут vCard `RELATED` и `MEMBER`
  (решение 25.09.2026); вопросы к кадрам — задача 7 в
  [to-typecase.md](to-typecase.md).
