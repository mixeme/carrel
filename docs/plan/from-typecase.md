# Записки из Typecase

Что из правок макета касается сервера. Макет правится в Typecase и копируется
сюда целиком (`docs/visual/carrel-ui-mockups.html`); здесь — то, что после
этого нужно сделать или знать серверной стороне. Обратный список — задачи
кадров, найденные сервером, — [to-typecase.md](to-typecase.md).

Прочитанное и сделанное удаляется; решения, которых нет в спеке, переносятся в
[architecture.md](../architecture.md). Разобранные записки — в истории git.

21. **Что есть в библиотеке для клиента** (Typecase `docs/development.md`,
   Р-25; `docs/guide/screen.md`).
   - **Формы и ссылки.** `Button.Href` — ссылка; `Button.Form` — кнопка вне
     формы отправляет `PostForm` (форма POST со скрытыми полями, CSRF,
     печатается где угодно на странице); `To`, `Name`, `Value` — куда и какое
     действие. `Form.Action`/`Method`/`Fields` — настоящая форма. `Name` у
     `Check`, `Seg`, `Pick` — флажок, радиокнопки, `select`: работают без
     сценариев. `Input.ReadOnly`/`Required`. `Href` у строк списков, пунктов
     меню, узлов дерева; строка с кнопкой внутри (отметка задачи) ссылкой не
     бывает. Карта контракта: `Action.Href` + GET — `Href`; POST — `Form` или
     `Submit` в форме, `To` — адрес; `FormRow` — поле с `Name`, `Options` —
     `PickOption`, `ReadOnly`, `Required`.
   - **Сверка экрана.** Пакет `carrel.dev/typecase/shape`: `Parse(макет)`,
     `Check(кадр, html)` — устройство (элементы, порядок, классы и состояния),
     не слова и не данные; ряд одинаковых соседей — любой длины; ссылка вместо
     кнопки и `select` вместо выбора — не расхождение. Пропажа одной из двух
     одинаковых по устройству кнопок подряд (Import рядом с Export) не видна.
   - **Черновик.** `frame2go -self <кадр>` — файл `package draft`, собирается
     в модуле клиента с одним `widget`.
   - **Изображение.** `Src` у `Avatar`, `Thumb` (с `Alt`), фото поля (`Photo`),
     `PhotoCrop`, `CardQR`.
   - **Поведения** (сценарий библиотеки, у каждого есть путь без сценария):
     `Check.Disables` (FormRow.Disables); `Button.Adds` + `Template`
     (InputAdd: `{n}` в имени — наименьшее свободное; без сценария кнопка
     отправляет форму за ещё одной строкой); `Seg.Theme` (тема в этом
     браузере, `tc-theme`); `Scrim.Drop` + `PostForm.File` (бросок файла
     отправляет форму импорта); лист по адресу — ссылка на `#id` листа,
     крестик `Close.Href: "#"` — так источники открываются на узком экране без
     сценариев (U-8); `List.Compact` — плотные строки; поле 16 px на
     сенсорном экране.
   - **Не сделано:** выбор столбцов — задача 29, идёт следом. Спеке клиента
     (U-5.7, U-8) — пробелы «формы и ссылки», «изображение», «плотное
     состояние», «кегль поля», «выбор источников на узком экране без
     сценариев» закрыты; остаются «выбор столбцов» и «страница на бумаге без
     маршрута».

## Для сведения — сервер не трогает

- **Подсказки «кандидат в дубликаты» в списках нет** (решение 24.09.2026):
  путь к паре — экран дубликатов; сворачивает строки только связывание.
- **Быстрая заметка** в кадрах — общий `NewSheet`, `/app/{kind}/quick`.
- **Столбец источника** — забота клиента (U-2.2).
- **Раскладка — забота клиента** (25.09.2026): панель подробностей 400 px на
  всех экранах, колонка заметки на весь экран — тоже 400 (в узкой рабочей
  области 296); поле во всю ширину занимает строку целиком; меню «⋯» полосы
  открыто только вместе с кнопкой и содержит то, что с полосы ушло.
- **«Упоминания»** — функция-кандидат; пока кадры не нарисованы и не
  утверждены, серверу строить нечего. В неё идут vCard `RELATED` и `MEMBER`
  (решение 25.09.2026); вопросы к кадрам — задача 7 в
  [to-typecase.md](to-typecase.md).
