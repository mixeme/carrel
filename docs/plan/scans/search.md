# Разведка раздела U-6.6 «Поиск»: пробелы контракта и вопросы к кадрам

**Что.** Выдача поиска `/app/search` (`SearchPage`), её адреса хода
`/app/search/progress/{task}` (SSE), `…/poll`, `…/retry`, `…/cancel`
(`PollBar`), подсказки поля поиска верхней панели (`SearchBox`: `History`,
`Jump`, `Whole`), рейл выдачи (`Rail`, рубрика «Sources a / b»).

**По какому коммиту.** Carrel `main` `1c2aa48` (сервер `v0.2.254`, клиент
`v0.4.40`); макет — сборка Typecase `95453f6` (копия
`docs/visual/carrel-ui-mockups.html` побайтно та же, что в `95453f6`,
сверено `cmp`).

**Каким способом.** Только чтение. Кадры `s-find-1` … `-3` вырезаны по
`data-frame` и прочитаны HTML; черновики `frame2go -self` напечатаны у всех
трёх — Typecase `95453f6` выгружен `git archive` во временную папку сеанса
(рабочее дерево `D:\Local\Git\typecase` стоит на `bd667a3` с чужими
правками — его не трогал). Фикстура одна — `app-search/normal` (запрос
«Ковалёва»); состояния без фикстуры читаны **по коду** обработчиков
(`carrel/server/internal/web/search.go`, `shell.go`, `combined.go`,
`timefmt.go`). Сервер не запускался. Старый скан — `docs/plan/client.md`,
«Раздел поиска: пробелы контракта (скан 03.10.2026)», ПА1 … ПЖ5: у каждого
его пункта ниже сказано, закрыт ли он.

Кадры почты ящика и упоминаний (`s-mailbox-14`, `-21`, `mentions-1`, `-2` —
в подписи `frag` «отложена») рисуют выдачу и хронологию с почтой; функции
отложены — в скан не входят, на них только ссылки.
