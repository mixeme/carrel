## 4. Новые пробелы серверу

### Администрирование

- **Ад37. «Send test» шлёт набранное, не сохранённое** (`s-admin-3`,
  подпись: «она шлёт то, что набрано в полях почты сейчас, сохранено оно
  или нет, — так релей проверяют до «Save» — и сама ничего не сохраняет»;
  ответ на задачу 158, записка 50). Сервер (`admin_settings.go:113`,
  `postAdminMailTest`): читает только `to`, шлёт через **сохранённый**
  релей (`sendSystemMail`), при несохранённой почте отвечает в `Test`
  «SMTP is not configured.». Нужно: проба — кнопка одной формы настроек со
  своим адресом (`Action` с `Href` — `formaction`), берёт Host, Port,
  Encryption, Username, Password (пустой — сохранённый), From address, From

  Просьба: `submit` с `formaction` в `s-admin-1`.
- **К2. Проверка установки — не форма** (`s-admin-4`). Поле адреса без

  ссылки `?show=`. Нужно: форма GET с полями действия и даты и кнопкой

  значит дата: «с этого дня», «за день», «до» (бывший В6).
