# Равенство родов: чего нет у одного из того, что есть у других

Разведка агентом 12.10.2026 по серверу `v0.2.212` (только чтение кода,
ничего не запускалось). **Находки не перепроверены** — перед правкой каждую
сверить с кодом. 14.10.2026 сверены и закрыты Р9, Р11, Р12, Р21 (сервер
`v0.2.230`), Р14 — не пробел; остальные ждут. Повод — правило владельца 12.10.2026 «роды равны»: поле,
действие, столбец или связь, которые есть у одного рода, есть у всех, если
формат не делает это бессмысленным; пробел закрывается без вопроса, кадру —
задача Typecase. «Related to» у события сюда не входит: сделано `v0.2.213`.

Пометки: **пробел** — похоже на недосмотр; **формат** — различие формата
(RFC 5545, vCard); **неясно** — надо смотреть.
