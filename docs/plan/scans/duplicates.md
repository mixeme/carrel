# Разведка U-6.7 «Дубликаты» и карточки сущности по кадрам

**Что.** Раздел U-6.7 спеки клиента: группы (`/app/duplicates`), решение
(`/app/duplicates/decide`), слияние (`/app/duplicates/merge`, GET и POST) и
смежная карточка связанной записи из объединённого вида (кадры
`s-contacts-33`, `s-agenda-25`, `s-tasks-17`, `s-notes-32`, записка 68), у
которой адреса ещё нет.

**По чему.** main `1c2aa48` (сервер `v0.2.254`, клиент `v0.4.40`); макет
`docs/visual/carrel-ui-mockups.html` — Typecase `95453f6`.

**Как.** По шагам 1–6 `docs/plan/scans/README.md`. Кадры вырезаны по
`data-frame="…"` до следующего `data-frame`. Черновик `frame2go` снят только
с `s-dup-1` (`go tool frame2go -self -root <Typecase 95453f6, git archive в
черновую папку> s-dup-1`); остальные кадры раздела — фрагменты или читались
по HTML. Фикстуры — `app-duplicates/normal`, `app-duplicates-merge/normal`.
Состояния без фикстур читались по коду (`internal/web/duplicates.go`,
`duplicates_merge.go`, `duplicates_card.go`, `internal/dupes/merge.go`) —
помечено «по коду». Сервер не запускался. Старый скан (client.md, «Раздел
дубликатов: пробелы контракта (скан 03.10.2026)», ДбА1…ДбЖ4) сверен с
CHANGELOG сервера и server.md: что закрыто — ниже, в «Закрыто со старого
скана».
