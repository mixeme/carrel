# Собрать остальные экраны через оболочку

**Composer.** Хвост сборки экранов из виджетов: `/notes` собирается через `Node`
и `SideBlock`, остальные экраны демо всё ещё склеивают `tc-shell` строкой
(`shellWrap`) и пишут `<main class="tc-main"` вручную. Ворота `screens-compose`
смотрят только `notes.go`.

Правило прежнее: один коммит на пункт, сначала проверка, которая краснеет на
текущем коде, потом правка.

---

## Почему это осталось

План сборки закрыл вход `tc-main` / `tc-bar` / `tc-side` на кадрах заметок и
хвост L-4.4 у `tc-seg` и `tc-top`. Оболочку целиком он не трогал: `Shell.Render`
всегда выпускает колонки рейла и панели, даже пустые, а флага «без рейла» у
оболочки нет и не будет.

На 375 px страница уже не даёт горизонтальной прокрутки; вылет отдельных узлов
(`OutOfBounds`) всё ещё за узкой веткой `view.width > 400` в `screens_test.go`:
панель действий и крошки.

---

## Закрытые развилки

Эти решения не пересматриваются. Нет в списке — смотреть спеку и кадр 7.4.

**Не заводить `NoRail` / `HideSide` у `Shell`.** Правка без рейла — не состояние
оболочки: `notes-edit` собирает `Top` + `Main` без колонок. Пустой `Rail` /
`Side` не должен занимать колонку — это нулевое значение, не флаг.

**`screens.css` без селекторов `.tc-`.** Нужный стиль — дыра библиотеки.

**Один тип сборки уже есть — `Node`.** Не заводить второй. `Overlay.Body` и
`Dialog` в этом плане не переводить на `[]Node`.

**Кадр 7.4 побеждает** таблицу ячеек и список содержимого, когда они расходятся.

**Узкая раскладка — в `tc.js`, не полем Go.** `tc-shell--narrow` ставит скрипт.
Порог 640 у оболочки и 720 у `tc-tickrow` сюда не копировать.

## Задача

### 1. `Shell` не рисует пустые колонки

Спека: режима «во весь экран без оболочки» нет; режима «без рейла» у оболочки
тоже нет. Пустой `Rail` сейчас всё равно занимает 264 px, поэтому `notes-edit`
собирает каркас строкой.

- [x] Нулевое значение `Rail` / `Side` не выпускает колонку (нет поля-флага)
- [x] Ворота: `notes-edit` собирается через виджеты, без ручного
      `<div class="tc-shell"`

### 2. Остальные экраны демо без `shellWrap` и ручного `tc-main`

- [x] `files`, `contacts`, `io`, `duplicates`, `states` — через виджеты
- [x] Ворота `screens-compose` на все `screens/*.go`, не только `notes.go`

### 3. Вылет узлов на 375 px

Страничный `scrollWidth` уже меряется. `OutOfBounds` по потомкам на 375 px всё
ещё пропущен: `tc-bar` и `tc-crumbs`.

- [x] `tc-bar` / `tc-crumbs` не вылезают из вьюпорта на 375 px
- [x] Браузерная проверка включает `OutOfBounds` на 375 px

## Что не чинить

Норма, не поломка — см. [reviews.md](reviews.md), «Каталог Typecase».

- Вертикальных отступов у ячеек таблицы нет: высота `--tc-row-height`.
- Пустые закрытые состояния невидимы по определению.
- «Build information missing» — верное поведение при пустом `RailFoot.Build`.
- Широкое поле поиска в `tc-top` на широком экране — объявленная геометрия.
- Цвет метки несёт `data-tc-colour`, не `style`.
- `screens.css` не содержит селекторов `.tc-`.
