# План: Typecase

Спека: [typecase.md](../spec/typecase.md). Раскладка и пины: [architecture.md](architecture.md). Ревью: [reviews.md](reviews.md).

Модуль — папка `typecase/`, `module carrel.dev/typecase`. О Carrel не знает. Runtime-зависимостей нет.

Исполнитель — Composer, кроме чекбоксов с **Opus**.

---

## Что нельзя

- Слоты с готовой разметкой, поля `template.HTML` на входе.
- `style=`, обработчики в атрибутах, блоки `<script>` / `<style>` в разметке виджета.
- Доменные слова в именах виджетов, полей, состояний. Список для ворот: `DAV`, `vCard`, `iCal`, `contact`, `calendar`, `note`, `task`, `file`, `collection`, `account`, `Carrel`, `caldav`, `carddav`.
- Геометрию снаружи (пиксели ширин, пороги отступления).
- Вложенные меню, лист в листе, дерево в дереве.
- Сборщик, npm, CDN, готовые бандлы в git.
- Откладывать ворота L-8 «на конец».

Каждый виджет: восемь пунктов L-3.2 (в `doc.go` или комментарии над типом входа) **и** код. Пункт без содержания — слово «нет».

Каталог `cmd/catalog` появляется с первой семьёй и с тех пор запускается.

## Ворота L-8 и каталог

Наращивать вместе с семьями, не отдельным «потом».

- [x] Полнота: разметка без стиля / стиль без виджета — красное
- [x] Владение: класс `tc-*` вне модуля — красное
- [x] Имена узлов: безымянный узел внутри виджета — красное
- [x] Типизированный вход: поле, принимающее разметку — красное
- [x] Перечисления: два булевых там, где состояние одно — красное
- [x] Именование по роли: доменное слово — красное
- [x] Формат описания: не все 8 пунктов — красное
- [x] Каталог: виджет не во всех состояниях — красное
- [x] Проверяемость: инвариант без теста L-9 — красное
- [x] Без встроенного: обработчик / блок сценария или стиля — красное
- [x] Доступность: нажимаемое без имени, поле без подписи — красное
- [x] Каждая автоматическая проверка однажды показана красной (L-9.3 / C-16)

- [x] Каталог: каждый виджет в каждом состоянии, одна команда, без приложения

## Браузерные проверки L-9.2

- [x] Подпись не пересекается со стрелкой меню ни при какой длине

- [x] Длинная подпись обрезается многоточием в своей ячейке
- [x] Панель при любой ширине — одна строка
- [x] Узкая раскладка: зона нажатия ≥ 44 px
- [x] После закрытия наложения фокус на вызвавшем контроле
- [x] `Esc` закрывает верхний слой и не трогает нижний
- [x] Контраст текста в обеих темах не ниже порога WCAG AA
- [x] Между темами прямоугольники не меняются

- [x] L-9.3: для каждого инварианта — сломанный вход в `testdata/broken/`, соответствующая проверка краснеет; не краснеет — красные ворота набора
