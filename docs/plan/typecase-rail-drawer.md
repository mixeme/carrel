# Узкий рейл — выдвижная панель

**Composer.** Хвост сборки экранов через оболочку: на 375 px колонка рейла
схлопывается (`width: 0`), а `tc-nav` / `tc-rail` уезжают за край
(`translateX(-100%)`). Кнопки открыть панель нет: `data-tc-rail-toggle` в
`tc.js` есть, в разметке экранов и в `Top` — нет. Спека L-4.1: в узкой
раскладке рейл — выдвижная панель на весь экран, закрывается кнопкой
применения.

Правило прежнее: один коммит на пункт, сначала проверка, которая краснеет на
текущем коде, потом правка.

---

## Почему это осталось

План оболочки закрыл пустые колонки, сборку экранов через виджеты и вылет
`tc-bar` / `tc-crumbs` на 375 px. Рейл спрятали, чтобы он не занимал 264 px
и не вылезал из вьюпорта. Выдвинуть его обратно нечем.

Закрытые развилки — в [reviews.md](reviews.md), «Оболочка Typecase». Нет в
списке — смотреть спеку L-4.1 (`tc-shell`, `tc-rail`) и кадр 7.4.

---

## Задача

### 1. Открыть и закрыть рейл в узкой раскладке

Спека: ниже порога рейл — выдвижная панель, не пропавший столбец. Сейчас
`tc-shell--narrow` прячет колонку без контрола. `dblclick` по чипам на
телефоне недоступен, и чипов может не быть.

- [ ] В узкой раскладке есть контрол, который открывает рейл
- [ ] Открытый рейл — выдвижная панель, закрывается кнопкой, `Esc`, возврат
      фокуса
- [ ] Ворота: браузерная проверка на 375 px открывает рейл и видит `tc-nav`
      / `tc-rail` во вьюпорте; закрытый рейл по-прежнему не даёт
      `OutOfBounds` и не даёт горизонтальной прокрутки страницы
- [ ] Узкая раскладка по-прежнему в `tc.js`, не полем экрана

### 2. Не плодить второй выдвижной механизм

Уже есть `tc-rail--drawer` и `data-tc-rail-toggle`. Узкая оболочка рисует
другой `position: fixed` на детях колонки. Один из двух должен остаться.

- [ ] Один способ выдвинуть рейл, не два CSS-пути
- [ ] Каталог `tc-shell` / `narrow` показывает тот же механизм, что экраны

---

## Что не чинить

- Пустой `Rail` / `Side` не выпускает колонку — это не «спрятать рейл».
- `notes-edit` без колонок — нулевое значение, не узкая раскладка.
- `Overlay.Body` и `Dialog` не переводить на `[]Node` в этом плане.
