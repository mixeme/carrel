# План: сервер

Спека: [carrel-server.md](../spec/carrel-server.md), шов: [carrel-common.md](../spec/carrel-common.md). Раскладка и пины: [architecture.md](architecture.md). Ревью: [reviews.md](reviews.md).

Модуль — папка `carrel/server/`, `module carrel.dev/carrel/server`. Не корень репозитория и не корневой `server/`. Typecase не импортирует.

Исполнитель — Composer, кроме чекбоксов с **Opus**. Аудиты Fable — в [reviews.md](reviews.md), после соответствующих слоёв, не вместо них.

---

## Что нельзя

- Шаблоны, CSS, `tc-*`, имена виджетов.
- `import` пакета Typecase из любого пакета этого модуля, включая `cmd`, **в рамках этого плана**. (Когда появится клиент, импорт будет только в `cmd/carrel`, не в `internal`.)
- Пересборка объекта из полей формы; экспортируемое «сырое» тело.
- Запись без предусловия (S-8).
- `map[string]any` во вью-моделях.
- SQLite, Redis, соседние процессы.
- Буферизовать файл целиком в `[]byte` на пути скачивания.
- Ответ 500 на молчание чужого DAV-сервера.
- Различимый ответ «нет / чужое / отозвано / истекло» для секретов.

Слои — как S-1. Обработчики HTTP — после модели. До них пакет тестируется своими тестами.

## Конфигурация и крипто

- [x] `internal/conf` — все переменные C-12 и `CARREL_DAVLOOM_PORT` (пусто = выкл.). Файл в каталоге данных, env перекрывает. У всего есть умолчание. Сроки сессий, TTL секретов, 1 МиБ форм, вёдра частоты, длины паролей — константы из [architecture.md](architecture.md), не новые `CARREL_*` и не поля экрана настроек
- [x] **Opus.** Типы `Object` и `Patch`, закрытая таблица операций патча (S-7). Код применения — Composer, сигнатуры — нет
- [x] `internal/crypt` по [architecture.md](architecture.md): два Argon2id, XChaCha20-Poly1305, AAD, ключ сервера `O_EXCL`
- [x] Тесты S-30.1: KDF независимы; смена пароля сохраняет ключ данных; wipe делает блоб нечитаемым; AAD не даёт подставить шифротекст

После `crypt` + `store` + `session` + стража — первый аудит Fable ([reviews.md](reviews.md)).

## Хранилище и сессия

- [x] `internal/store`: один файл состояния, `CRL1`, атомарная запись, reject более новой версии
- [x] Неудачная запись не оставляет ни изменения, ни строки журнала
- [x] Счёт подключений человека без открытия блоба
- [x] Журнал аудита: кто / что / с кем; никогда пароль, токен, тело записи
- [x] `internal/session`: ключ данных, CSRF, простой 12 ч / абсолют 7 суток, кэш, черновики, история 10, реестр потерь, не больше 4 живых вееров
- [x] Кэш: ключ с версией; тела вытесняются раньше карт; потолок процесса через все сессии
- [x] Выход, истечение, перезапуск затирают ключи и кэш

## Пользователи

- [ ] Две роли; пустой том → `/setup`; пароля по умолчанию нет
- [ ] Приглашение, пароль от администратора, саморегистрация — как S-10.2. Срок приглашения 7 суток, подтверждение адреса 48 ч, пароль ≥ 8

- [ ] `/forgot` и `/forgot/{token}` — двухшаговая очистка, не восстановление ключа; срок ссылки 24 ч
- [ ] `cmd/carrel-wipe` — одноразовая ссылка в stdout, в журнал; срок 15 мин
- [ ] Депонирование выключено по умолчанию, не задним числом, формулировка честная
- [ ] Один `UnlockSheet` и одни часы на все выдачи секретов
- [ ] Последнего администратора нельзя удалить, понизить, отключить
