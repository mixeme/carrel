## Открыто

- [ ] **Замена адреса в карточке → переписать участников** (S-15.4, решение
      владельца 24.09.2026). Ждёт кадра — задача 1 в
      [to-typecase.md](to-typecase.md). Сервер тогда: обнаружение запоминает,
      объявлен ли `schedule-outbox-URL`; сохранение карточки видит замену
      адреса. Адрес удалён — ничего; заменён один — старый переписывается на
      новый; заменено несколько — каждый убранный на адрес по умолчанию, и
      вопрос называет пары. Поиск записей — как `relink`, в отмеченных
      коллекциях; `ORGANIZER`, `ATTENDEE`, `SENT-BY`, `DELEGATED-*` с
      параметрами (`CN`, `PARTSTAT`, `ROLE`, `RSVP`), запись с `If-Match`.
      Планирование объявляют Nextcloud, Baikal, SoGo, Yandex, Google; у
      Mail.ru принципала нет, Xandikos RFC 6638 не реализует.
- [ ] **Пароль нельзя стереть через форму подключения**: пустое поле — «не

      кадра — задача 2 в [to-typecase.md](to-typecase.md).
