# Наборы для сверки экранов с макетами

Эти файлы содержат ровно те записи, что нарисованы в
[carrel-ui-mockups.html](../carrel-ui-mockups.html). Их загружают в пустой
экземпляр и открывают те же экраны: если вёрстка сделана по макету, отличий
не будет — ни в колонках, ни в порядке строк, ни в состояниях.

Сверка нужна затем, что макет — HTML, а не картинка, и глазами разница в
одну колонку или в один разъехавшийся флажок не ловится. С одинаковыми
данными два окна можно поставить рядом.

## Как загрузить

1. Завести два подключения с именами `nextcloud · home` и `radicale · vps`
   — имена аккаунтов попадают в колонку «источник», и без них строки будут
   подписаны иначе, чем в макете. Нужны **два разных сервера или два разных
   пользователя**: одно подключение к тому же principal вторым не станет —
   discovery отдаст обоим один и тот же список коллекций. Одного тестового
   Baikal для этого мало; второй сервер поднимается локально одной командой:

   ```bash
   python -m pip install --user radicale
   python dev/radicale-run.py --config dev/radicale.conf   # 127.0.0.1:5232
   ```

   Запускается через обёртку не для красоты: на Windows Radicale падает на
   старте с `WinError 1314` — он пробует создать симлинк, чтобы записать в
   лог одну строку про поддержку симлинков, а прав на симлинк у обычной
   учётки нет. Обёртка до старта подменяет `pathutils.path_supports_symlink`
   на «нет». Конфигурация и обёртка лежат в `dev/` (в git не отслеживается).

2. Завести коллекции с именами из таблицы и цветами из макета:
   Личный и Контакты и Записи и Дела — `#4A6B52`, Работа — `#3F6E8C`,
   Архив и Дни рождения — `#A05A2C`, Команда, Проекты и Дневник — `#6B4E7A`,
   Дежурства — `#8C6239`. Коллекции создаются самим Carrel (**New
   collection**); Radicale до первой коллекции подключить нельзя — discovery
   не находит ничего и отказывает, поэтому одну на нём заводят через
   `MKCALENDAR` руками.

   Компоненты у коллекции — те, что она держит: Дела — `VTODO`, Записи и
   Дневник — `VJOURNAL`, Работа — `VEVENT` и `VTODO` (в неё идут и
   `rabota.ics`, и `rabota-zadachi.ics`), остальные — `VEVENT`.

3. В каждой коллекции нажать **Import** и указать её файл. **Кроме заметок:**
   `zapisi.ics` и `dnevnik.ics` грузятся через **Import календаря** в свою
   коллекцию. Импорт заметок принимает Markdown, а не `.ics` (§23.9), и
   `.ics` с `VJOURNAL` ему подсунуть нечем — календарный импорт эти же
   записи принимает и раскладывает как заметки.

## Что совпадёт, а что нет

**Совпадёт:** состав и порядок строк, группы («А» — 3, «В» — 2; понедельник
10 августа — 3, вторник 11 августа — 2), колонки, значки состояний, карточка
события со всеми полями, полноэкранная правка заметки.

Отдельно проверяются четыре вещи, ради которых наборы и собраны такими:

- **Исходный часовой пояс.** «Синк-ап по релизу» заведён с
  `TZID=Asia/Yekaterinburg` на 12:00 — это 10:00 в Москве. На экране должно
  стоять московское время и метка исходного пояса рядом (§23.8). Если метки
  нет, встреча показана «не в то время» и никак об этом не говорит.
- **Дубликат в двух источниках.** «Дежурство: первая линия» лежит в
  `rabota.ics` и в `dezhurstva.ics` **разными UID** — одинаковый UID был бы
  одним объектом, а не дубликатом. В агенде это одна строка со значком
  «duplicate? ×2» и источником «2 sources».
- **Связанные карточки.** Артём Белов лежит в двух книгах разными записями,
  и до связывания это группа в «Дубликатах», а после — одна строка со
  значком «linked ×2».
- **Чужие свойства.** У карточки Анны Ковалёвой три свойства, которых Carrel
  не знает (`X-EVOLUTION-FILE-AS`, `X-ABLABEL`, `X-CARREL-UNKNOWN-FLAG`).
  Карточка должна сказать «Kept as the server sent them · Show 3» и вернуть
  их на сервер нетронутыми.

**Не совпадёт — и не должно:** счётчики коллекций в рейле. В макете стоят
248, 51, 13, 86, 401 — числа большого настоящего архива, они там затем,
чтобы показать, как выглядит колонка с четырёхзначным кодом ответа рядом с
трёхзначным счётчиком. Набор из пяти карточек даст пять. Сами макеты в этом
месте себе противоречат: книга на 248 карточек нарисована пятью строками, и
иначе список показать нельзя. **Сверяется устройство экрана, а не итог
пересчёта.**

Недоступного `baikal · office` в наборах нет: чтобы получить строку с 401,
подключение заводят с неверным паролем — файлом это не задаётся.

## Правка

Файлы собирает [`make-fixtures.py`](make-fixtures.py):

```bash
python docs/visual/fixtures/make-fixtures.py
```

Руками их лучше не править: и vCard, и iCalendar считают длину строки в
октетах, а кириллическая строка сворачивается не там, где кажется по буквам.
`TestMockupFixturesParse` в `internal/model` читает каждый файл парсером
самого репозитория и заодно проверяет CRLF и свёртку.
