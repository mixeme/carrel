## Модули

Монорепозиторий. Сервер — `carrel/server/`, `module carrel.dev/carrel/server`,
AGPL-3.0-or-later; не корень репозитория и не корневой `server/`. Typecase
(`carrel.dev/typecase`, MIT) с 10.09.2026 живёт в своём репозитории. Клиент —
**отдельный модуль** `carrel.dev/carrel/client` в `carrel/client/`
(решение владельца 28.09.2026): импортирует `carrel.dev/carrel/server/view`,
открытый пакет отрисовки сервера `carrel.dev/carrel/server/render` и
Typecase; `internal/*` ему недоступны. Сервер импортирует клиент только из
`cmd/carrel` — через него же, и только там, в граф сервера входит Typecase.
Typecase подключается меткой выпуска; пока меток нет, клиент её не
подключает. Пока клиент не печатает HTML, `cmd/carrel` его не подключает и
сервер отвечает `render.JSONRenderer`.

`VERSION` в корне — версия продукта. `THIRD_PARTY.md` — в том модуле, куда
добавили зависимость, тем же коммитом.

```
carrel/server/
  cmd/carrel/ cmd/carrel-wipe/
  view/                  C-6, C-8, C-9; JSON-теги = фикстуры
  render/                C-7.1–C-7.3: Renderer, заголовки, цели, OOB, JSONRenderer
  internal/conf crypt store session sealed
  internal/dav discover model
  internal/provider/{card,cal,file}
  internal/photo fanout dupes web user mail backup publish proxy
  integration/           живой набор, -tags=integration
  testdata/ scripts/ Dockerfile docker-compose.linux.yml
carrel/client/           module carrel.dev/carrel/client; require server (replace ../server)
  zone/                  зона вью-модели страницы по цели C-7.2
  screens/               экраны: только вызовы виджетов (U-5.2); пока пуст
  guard_test.go          защиты U-15.2: импорты, строки, файлы, реестры
  testdata/              нарочно испорченные образцы — укусы защит
```

Зависимости только вниз: `web` → `view`, `render`, `session`, `store`, `fanout`,
провайдеры → `model`, `dav` → страж, `discover`; `store` и `session` → `crypt`.
Транспорт не знает календарь, модель не знает запрос, провайдер не знает
разметку. Страницы собирает `web`; `fanout`, `dupes`, `photo`, `backup`,
`publish`, `mail`, `proxy` не импортируют `internal/web` и не заполняют
`*Page` / `Shell` / `Action`. Исключения провайдеров: goldmark →
`[]view.Block`, `card.Foreign` → `[]view.Field`. Общего `internal/provider`
нет: интерфейс источника — в `internal/fanout`.

**Пока клиент не печатает HTML** страницы, фрагменты и листы отвечают JSON
вью-модели (`render.Renderer`, сейчас `render.JSONRenderer`). Потоки, файлы,
SSE, DAV, редиректы, `/healthz` — настоящие. `render` знает только контракт
C-7.1–C-7.3 — ни разметки, ни имён виджетов; `view` и `render` — всё, что
клиент видит у сервера.

## Закрытые развилки

Не пересматриваются в ходе работы; нет в списке — спека, не третье.
Развилки безопасности — в [security.md](security.md).

**Патч.** Закрытый набор операций (`SetText`, `AddValue`, `RemoveProp`, …);
пустое значение ≠ удаление; UID и VERSION не патчатся; после PUT —
перечитать и `LossReport`. VALARM — `cal.SetAlarms`, не новая операция.
Адрес участника во всех компонентах записи (главном и переопределённых
случаях) — `cal.RewriteAddresses`, тоже правка документа: патч достаёт только
главный компонент (S-15.4).
Составные значения сравниваются по частям (SV-27), правило серии — как
правило, не строка (SV-35).

**Провайдеры.** Создание — `If-None-Match: *` (`dav.Creator.PutCreate`),
обновление — `Put` с ETag. PHOTO по URI провайдер не забирает — только
`internal/photo` через страж. `Expand` собирает `rrule.Set` (RRULE − EXDATE
+ RDATE). `Join` отвергает `.`, `..`, пустое, слэши. Известные свойства vCard
— те, для которых в C-6 есть место; прочее — `Foreign`. `Transport` не
расширяется: копия — `Get` + `PutCreate`; сырой HTTP davloom —
`dav.Client.Forward` рядом с ним. `Get` тела файла без потолка; потолок C-12
— на PROPFIND и REPORT.

**Каталог в блобе — кэш сервера**, не данные человека: имя, цвет, виды
берутся из ответа сервера (SV-41, SV-43). Новая коллекция с сервера сама не
встаёт — повторное обнаружение предлагает разницу. Галочки — `Selected` в
блобе; пустой выбор — пустой экран, не «все».

**C-10.** Английские строки как в кадрах. Пояс — один на экземпляр; 12/24 и
первый день недели — из аккаунта. Цвет метки — с сервера, иначе SHA-256 пути
→ шесть тонов макета (`s-profile-7`: `#4a6b52 #3f6e8c #6b4e7a #a05a2c #8c6239
#9a9280`); палитра формы — те же шесть, аватары — они же. Цвета, которые
Carrel записал на серверы до смены палитры (28.09.2026), остаются: это цвет
сервера.

**Slug.** NFD → таблица кириллицы (`internal/web/slug.go`) → lower → пробелы и
дефисы в один `-` → `[a-z0-9-]` → пусто = `col` → занято `-2`. Адрес вручную
— один сегмент `[A-Za-z0-9._~-]`; `..`, `/`, ведущая точка — отказ.

**ID.** Crockford base32, 10 знаков из 6 случайных байт, префикс рода: `a-`
подключение, `u-` человек, `i-` приглашение, `t-` задача веера, `q-` строка
передачи, `b-` задание копии, `d-` устройство, `f-` подписка; `m-` занят за
почтовым ящиком. UID записи на DAV — 32 hex из 16 байт.

**URL.** `{col}` — один сегмент, `/` → `%2F`. `{path…}` у файлов —
посегментно; `..` отвергать, не нормализовать.

**Дубликаты.** Email 60, телефон (10 последних цифр) 60, UID 80, имя 20, день
рождения +10, заголовок + дата у событий, задач и заметок 70; порог 60.
Сравнение только внутри корзины сильного ключа. Веса и порог — умолчание
экземпляра (`CARREL_DUPLICATES_*`) и своё у человека в блобе. Только по
загруженному, без запроса к серверам.

**Веер.** Задача — объект в сессии. Потолок `FanoutParallelism` считает
запросы в полёте: слот берётся вокруг одного запроса и сразу отдаётся, никто
не держит слот, ожидая слота. Источник называет число своих запросов
(`fanout.Asks`) и получает бюджет на каждый. Паника источника ловится на
каждом роде (`fanout.AskingKind`).

**Сеть.** Пул соединений общий, кэш транспорта в стороже по отпечатку
сертификата; `MaxIdleConnsPerHost` 10, `MaxIdleConns` 100 — без нагрузочной
проверки. Запись повторяется, только если соединение взято из пула
простоявшим и тело можно отдать снова (SV-14); страж говорит, какое правило
применил. Таймаут файла — простой, не весь запрос.

**Кэш S-4.2** (`internal/web/wholeread.go`). Целое чтение коллекции — карта
«путь → версия» и тела под меткой изменения; перед чтением PROPFIND глубины 0
за `getctag` / `sync-token`, та же метка — ни одного REPORT; без метки —
мягкий срок. Поиск по хранимому — просеиванием у нас. Окно агенды хранится
под своим окном, как ответил сервер. Своя запись сбрасывает чтения
коллекции; «Refresh» и `again=1` — все чтения сессии.

**Подключение.** Подпись уникальна: вторая такая же (сравнивается действующая, пустая — это адрес сервера) — ошибка поля при добавлении и при Edit (решение владельца 24.09.2026, `s-profile-11`). `{account}` переживает правку. Edit — новое обнаружение: без
успешного `discover.Run` не сохраняется, разница каталога — предложением.
Test — только чтение, след в сессии. Disconnect одним `editBlob` и одной
строкой `connection.remove` снимает подключение, его коллекции, галочки,
`LastUsed`, участников связанных групп (группа из одного распускается),
`DeviceExcluded`, источники заданий копии (задание с этим назначением
остаётся и помечается), папку вложений и `UploadTo`, записи ссылок; в
`state.enc` — его ссылки с конвертами и коллекции в областях устройств. На
сервере не трогается ничего.

**Формы.** Категории — одно поле списком. Метка строки — выбор плюс то, что
уже стоит. Адрес — пять частей ADR. Повторение правится целиком: простые поля
собирают `RRULE`, «Advanced RRULE» главнее; `EXDATE`, `RDATE`, экземпляры не
трогаются. Пояс события — `TZID`, по умолчанию «as sent»; список — все
пояса базы Go (`internal/web/zones.txt`, пишет `zones_gen.go`), база — в
бинарнике (`time/tzdata`), Floating снимает `TZID`. Повторяющиеся строки —
без пустой про запас, «Add …» — `InputAdd` с шаблоном строки. Mark done — POST
правки с `done=on` и версией. Имя: `Given` и `Family` пишутся в `N`, режется
только изменённое имя.

**Связи uid.** Перенос в SoGo и Google и слияние дубликатов перенаправляют
`RELATED-TO` на новый uid в отмеченных коллекциях. Импорт не перевязывает
лежащее на серверах никогда; связи внутри файла едут с ним (S-19).

**Вложения.** Порог `AttachInlineMax` 2 МиБ, коллекция может опустить через
`max-resource-size`. Имя файла в папке вложений — по выбору человека
(`Blob.AttachNames`): «дата имя» по умолчанию, «имя» или «заголовок - имя»;
занятое — номер, без вопроса. Решает одна функция (`attached`), источников
байтов два: загрузка с компьютера — крупное кладётся в папку вложений и
ссылка ведёт туда; файл из Files (`?op=attachfile`) — маленький читается
внутрь записи тем же путём, крупное не копируется, ссылка ведёт туда, где
он лежит (решение владельца 28.09.2026). Подписанная папка — не источник.

**Публикация и подписки.** Живое чтение, не копия. Ссылка целиком — в блобе
(`Blob.Links`), в `state.enc` — свёртка. Подписка — не коллекция сервера,
только чтение, дальше не публикуется. Opens считается на каждом открытии и
пишется с `LastSeen` не чаще раза в час; проверка «жива ли» — не открытие.

**davloom.** Второй `http.Server` в том же процессе (`CARREL_DAVLOOM_PORT`,
пусто — выключен; равен веб-порту — отказ запуска), bind — `CARREL_BIND`, TLS
нет — за прокси, свои вёдра, без кук, slog с `listener=davloom`. Показываемый
адрес — `{CARREL_PUBLIC_URL}/dav/`, без него `http://127.0.0.1:{port}/`.
Запись устройства — на `store.User`, не в блобе: обёртку снимают до ключа
данных. Пароль выдаёт сервер (32 байта), показывается один раз; потолка числа
устройств нет. GET `/` — `AboutPage`, дома `/cal/`, `/card/`, `/files/` —
каталог ∩ область устройства, `getctag` живым PROPFIND. Пакет `internal/proxy`. Href — `/c/{account}/{col}` с
префиксом пути адреса davloom (`/dav`). XML подменяется потоком; тело REPORT
— в памяти с длиной (Nextcloud отвечал 500 на чанки). Право у каждого
устройства своё — «read only» или «read and write»: у read-only запись
отказывается 403 `need-privileges` до сервера. В nginx
`proxy_pass http://carrel:8081;` **без URI**, иначе `%2F` декодируется; в
Apache — `AllowEncodedSlashes NoDecode` и `nocanon`.

**Почта — подготовка** ([carrel-mailbox.md](spec/carrel-mailbox.md), решение
владельца 28.09.2026: функцию не строим, ядро к ней готово). Ящик — свой срез
блоба `Blob.Mailboxes`, не `Connection` с родом: `Blob.Connections` обходят
десятки мест, и каждое ждёт DAV. `Blob.Connection()` ящик не находит.
Учётные данные ящика — объект (способ и пароль), чтобы рядом встал токен
OAuth без смены формата (M-3). Число подключений S-3 — только
`Blob.ConnectionCount()`, подпись занята — только `labelTaken`: ящик войдёт
туда же, в одно пространство подписей с серверами. Поиск спрашивает
`searchSources`, а код, которому нужна коллекция DAV, —
`tickedCollections`; тип источника не приводится. Происхождение строки
поиска и строки опроса — `sourceOrigin`. Письмо предлагается там, где
`canSendLetters(sess)`; от релея зависит только `relayOn()` (Reply-To).
`internal/mail`: From письма — `relayFrom`, письмо пишет `write` с любым From,
отправку делает `submit` с любым `submission` (сервер и конверт). С первым
ящиком поднимается `store.FormatVersion`: старая сборка, записав блоб,
выбросила бы ящики вместе с паролями, поэтому она должна отказаться его
открывать. Не делается до функции: вью-модели, маршруты `/app/mail/{mailbox}`,
переключатель `CARREL_MAILBOX_ENABLED`, коды журнала `mailbox.*`, набор
IMAP (зависимости в списке нет), экспорт наборщика стража без вызывающего.

**Markdown.** AST goldmark → `[]view.Block`, Kind только C-8; сырой HTML —
экранированный текст в `BlockPara`. Из расширений — только `TaskList` (тот же
модуль): пункт «- [ ]» — `BlockTask` с `Checked`; рендер HTML не вызывается.

**Фото.** `DecodeConfig` до декода; ориентация — тег 0x0112 из APP1 без
библиотеки EXIF; JPEG без EXIF; запись по RFC, потеря у Radicale —
`LossReport` с действием «сохранить в старом формате».

**Копия.** zip + `manifest.json`, по умолчанию age поверх; прогон перечитывает
и сверяет SHA-256; частичная копия не вытесняет целую. Восстановление — только
в новую коллекцию.

**Вью-модели.** Порядок, группы и сегменты списков — данные сервера,
выбранное помечено `On`. Число у рубрики, подпись «3 of 4 books», печать,
столбцы — клиент. Пустой список — `[]` (C-6.1). Штамп источника — подпись
подключения плюс имя коллекции везде. Анонимный embed `Shell`, JSON-теги
camelCase.

## Сроки и лимиты

Спека говорит «есть срок / есть лимит», чисел не даёт. Именованные константы
в коде (`internal/conf/limits.go` и пакеты-владельцы), не `CARREL_*`. Сессии,
TTL секретов, тело POST и частота — продуктовые, без владельца не трогать.

| Что | Значение |
|---|---|
| Простой сессии | 12 ч, администратор меняет (1–168 ч), действует сразу |
| Абсолютный срок сессии | 30 суток, администратор меняет (1–365 сут), для новых сессий |
| Приглашение | 72 ч, администратор меняет (1–720 ч) |
| Подтверждение адреса | 48 ч |
| Ссылка `/forgot` | 24 ч |
| Ссылка из консоли | 15 мин, одноразовая |
| Профиль устройства | 5 мин, одноразовая |
| Публичная ссылка по умолчанию | 30 суток; явный «без срока» разрешён |
| Тело обычного POST | 1 МиБ; фото и импорт — C-12; файлы — без потолка |
| Вход и регистрация | 5/мин на учётку и 20/мин на IP |
| Анонимные токены | 30/мин на IP; у `/p/{token}` ведро тратит только промах |
| Опубликованная ссылка | 120/мин на ссылку |
| После входа | не жёстче 120/мин на сессию |
| davloom | неуспех — 5/мин и 20/мин; успех — 120/мин на устройство |
| `/healthz`, «О сервисе», GET `/` davloom | без вёдер |
| Вееров на сессию / параллельность / задач в памяти | 4 / 4 / 10 |
| Пароль человека / мастер-пароль | от 8 / от 16 |
| Argon2id входа и обёртки / мастера | t=3, 64 MiB, p=1 / t=4, 256 MiB, p=1 |
| `AttachInlineMax` / `FileThumbMaxBytes` / `TransferQueueLen` | 2 МиБ / 512 КиБ / 50 |

Как применять:

- Простой сдвигает любой запрос с живой SID; абсолютный срок считается от
  входа и не сдвигается; что раньше, то и конец — ключи и кэш затираются.
- Приглашение: «Продлить» — now + срок, секрет прежний; «Отправить повторно»
  — новый секрет и новый срок.
- Подтверждение адреса истекло — повторная подача той же формой; запись сами
  не удалять.
- `/forgot` сгорает раньше срока, если задан новый пароль. Повтор консольной
  команды — новый секрет, старый мёртв.
- Профиль устройства — отдельно от `CARREL_UNLOCK_TTL`; GET сжигает ссылку.
