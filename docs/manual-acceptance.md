## 1. Каркас (этап 1)

Сборка с метаданными:

```bash
docker compose build \
  --build-arg VERSION=0.7.0 \
  --build-arg COMMIT=$(git rev-parse --short HEAD)
```

### A1–A3. Bootstrap и контейнер

- [ ] Пустой том → `/setup` → первый админ → повторный `/setup` → `/login`
- [ ] `docker compose ps` — `healthy`
- [ ] `read_only: true`, nonroot, `CapDrop: ALL`, порт только на loopback
- [ ] `/about`: версия и commit совпадают с сборкой

### A4–A9. Остальное

- [ ] SIGTERM не рвёт активный запрос; после restart сессии сброшены (A4)
- [ ] Логи без секретов (A5)
- [ ] SMTP диагностика: неверный хост / пароль / успех (A6)
- [ ] Письмо восстановления escrow (A7)
- [ ] Приглашение по ссылке без SMTP (A8)
- [ ] `THIRD_PARTY.md` актуален (A9)

### Локально уже проверенное (этап 1, §2a)

См. [stage-1-outstanding.md](stage-1-outstanding.md) §2a — при финальной приёмке убедиться, что незакрытые пункты отмечены или перенесены сюда.

## Автоматика (не дублировать руками)

Уже закрыто `go test ./...` / integration — см. §3 в [stage-1-outstanding.md](stage-1-outstanding.md) и шлюзы в `stage-N-plan.md`. Перед ручной приёмкой:

